# EngineeringOS
A private engineering wiki for projects, knowledge, playbooks, and learning.

## Two-vault boundary (read once)
- **EngineeringOS** = engineering, code, systems, agent/automation domain, technical research.
- **SecondBrain** (`~/Documents/SecondBrain`) = personal life, journal, people, reading, learning reflections.
- Rule of thumb: if it helps you *build or operate software*, it goes here. If it's about *your life/people*, it goes to SecondBrain. Cross-link between them; don't duplicate.

## Daily notes
- Daily notes live at root as `YYYY-MM-DD.md` (template: `60 Templates/Daily Note.md`).
- The maintenance cron creates today's note if missing and links inbox captures. You don't create them by hand.

## Structure
| Folder | Purpose |
|--------|---------|
| `00 Inbox` | Quick capture, sort later |
| `10 Projects` | Active projects with end dates |
| `20 Knowledge` | Permanent technical knowledge |
| `30 Playbooks` | How I do things (runbooks) |
| `40 Learning` | Books, courses, research |
| `50 Resources` | PDFs, images, links, cheatsheets |
| `60 Templates` | Reusable note templates |
| `90 Archive` | Finished projects, old notes |

## Principles
- **10-second rule**: If you can't decide where a note goes in 10 seconds, the system is too complex.
- **Grow on demand**: Don't create folders until you have enough notes to justify them.
- **Organize for today**: Build for the person you are, not the person you hope to become.
